Roomy - Web Application 

PROJECT OVERVIEW
--------------------------------------------------------------------------------

Roomy is a modern, full-stack web application designed to simplify shared 
living arrangements by providing comprehensive tools for roommate coordination, 
financial management, and household task organization. The platform enables 
users to create or join apartments, manage rent payments through flexible 
payment models, coordinate household chores, maintain shared grocery lists, 
and communicate availability status with co-habitants.


CORE FEATURES
--------------------------------------------------------------------------------

1. User Management
   - Secure user registration and authentication
   - Personalized user profiles with customizable status messages
   - Status indicators (Available, Busy, Working, Cleaning, Away, Custom)
   - Biography and contact information management

2. Apartment Management
   - Create and configure shared living spaces
   - Invite roommates via apartment ID system
   - Track apartment details (complex name, room number, rent information)
   - Automatic creator-to-apartment association
   - Multi-roommate support with residence tracking

3. Payment Management
   - Two payment models:
     * Split Payment: Divides rent equally among all roommates
     * Queue Payment: Rotates payment responsibility monthly
   - Configurable rent amounts and due dates
   - Payment queue system with automatic rotation
   - Persistent payment configuration
   - Fallback logic for single-occupant apartments

4. Chore Tracking
   - Create and assign household tasks
   - Support for one-time and recurring chores (daily, weekly, monthly)
   - Chore completion tracking with timestamps
   - Assignment management system
   - Due date scheduling and monitoring

5. Grocery Management
   - Shared shopping lists per apartment
   - Category-based organization (Dairy, Produce, Meat, Grains, Snacks, 
     Beverages, Frozen, Bakery, Other)
   - Purchase status tracking
   - Quantity specification
   - Contributor tracking (who added each item)

6. Roommate Directory
   - View all current roommates in shared apartment
   - Real-time status visibility
   - User profile access
   - Apartment membership management

7. Dashboard
   - Centralized overview of apartment information
   - Quick access to upcoming payment obligations
   - Chore status summaries
   - Status update functionality
   - Navigation hub to all features

8. Expense Calculator
   - Built-in calculator for cost splitting
   - Modern gradient-based design
   - Supports standard mathematical operations

DATABASE SCHEMA
--------------------------------------------------------------------------------

Core Tables:
- users: User account information and status
- apartments: Shared living space details and rent configuration
- residence: Many-to-many relationship between users and apartments
- chores: Task definitions and recurrence settings
- chore_assignments: Links chores to assigned users
- groceries: Shopping list items with category and purchase status
- rent_payments: Payment records with type and completion status
- payment_queue: Rotation order for queue-based payment system

Key Relationships:
- Users can belong to multiple apartments (via residence table)
- Apartments have one creator but multiple members
- Chores are apartment-specific with user assignments
- Groceries are tied to specific apartments
- Payment queue maintains rotation order per apartment

Database Functions:
- calculate_split_rent(): Divides rent equally among apartment members
- get_next_queue_payer(): Calculates next payer in rotation sequence

Views:
- rent_summary: Aggregated payment information across apartments


API ENDPOINTS
--------------------------------------------------------------------------------

User Management:
- GET    /api/users                  - Retrieve all users
- POST   /api/signup                 - Create new user account
- POST   /api/login                  - Authenticate user
- PUT    /api/users/{userId}         - Update user profile
- PUT    /api/users/{userId}/status  - Update availability status

Apartment Management:
- GET    /api/apartments             - List all apartments
- POST   /api/apartments             - Create new apartment
- GET    /api/apartments/{id}        - Retrieve specific apartment
- PUT    /api/apartments/{id}        - Update apartment details
- DELETE /api/apartments/{id}        - Remove apartment
- GET    /api/apartments/creator/{userId} - Get user's created apartments

Residence (User-Apartment Links):
- GET    /api/residence/user/{userId}        - Get user's apartment ID
- GET    /api/residence/apartment/{aptId}    - Get apartment members
- POST   /api/residence                      - Add user to apartment
- DELETE /api/residence/{residenceId}        - Remove user from apartment

Chore Management:
- GET    /api/chores/apartment/{aptId}  - List apartment chores
- POST   /api/chores                     - Create new chore
- PUT    /api/chores/{choreId}           - Update chore details
- PUT    /api/chores/{choreId}/complete  - Mark chore complete
- DELETE /api/chores/{choreId}           - Remove chore

Grocery Management:
- GET    /api/groceries/apartment/{aptId}    - List apartment groceries
- POST   /api/groceries                      - Add grocery item
- PUT    /api/groceries/{itemId}/purchased   - Mark item purchased
- DELETE /api/groceries/{itemId}             - Remove item

Payment Management:
- GET    /api/rent/apartment/{aptId}  - Get payment records
- POST   /api/rent                    - Create payment record
- PUT    /api/rent/{rentId}           - Update payment details

Payment Queue:
- GET    /api/payment-queue/{aptId}          - Get rotation order
- POST   /api/payment-queue/initialize       - Set up new queue
- POST   /api/payment-queue/add              - Add user to queue
- DELETE /api/payment-queue/remove           - Remove user from queue
- GET    /api/payment-queue/{aptId}/current-payer - Get current month's payer

Calculator:
- POST   /api/calculator/calculate  - Perform mathematical operations

All endpoints support CORS for http://localhost:5173 and http://localhost:5174.

KNOWN FEATURES & EDGE CASES
--------------------------------------------------------------------------------

Payment System:
- Supports 0 roommates scenario (user pays full rent)
- Effective participants calculation: max(roommates.length, 1)
- Queue rotation based on (year * 12 + month) % queueSize
- Fallback to current user as payer when queue empty

Apartment Management:
- Creator automatically joins apartment upon creation
- Roommate count includes creator in display
- Supports joining via apartment ID for non-creators

Chore System:
- Recurring chores maintain schedule without duplication
- Completion tracking per assignment instance
- Supports multiple assignees per chore

Data Persistence:
- Payment settings (rent amount, type, due date) persist in database
- User status updates stored and displayed to roommates
- Grocery purchase status maintains history
